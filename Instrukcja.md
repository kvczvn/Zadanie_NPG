# Statki (Zadanie_NPG)

Taktyczna gra symulująca ekonomię i bitwy flot statków. Projekt w języku Python.

##  Szybki start
1. Zainstaluj zależności: `pip install -r requirements.txt`
2. Uruchom grę: `python statki.py`


## 📁 Struktura
* `src/` - kod gry
* `tests/` - testy jednostkowe
* `docs/` - dokumentacja
